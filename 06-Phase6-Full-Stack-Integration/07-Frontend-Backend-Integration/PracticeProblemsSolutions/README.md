# Topic 7 — Practice Problems Solutions

Vite + React + TypeScript scaffold integrating with the TaskFlow API. Builds on Topic 6 with TanStack Query, Zustand, MSW, and Vitest.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_USE_MOCKS=true` in `.env` to run fully offline against MSW handlers.

Demo creds (mocks): `demo@taskflow.dev` / `password123`.

## Scripts

- `npm run dev` — Vite dev server
- `npm run build` — production build
- `npm run typecheck`
- `npm run lint`
- `npm run test` — Vitest with jsdom + MSW node server
- `npm run api:gen` — regenerate typed client from Topic 4 Swagger

## Where to start (P1–P6)

| Problem | Files |
|---|---|
| P1 QueryClient + keys factory | `src/app/providers.tsx`, `src/features/projects/keys.ts`, `src/shared/lib/toast.ts` |
| P2 Login + Zustand store | `src/features/auth/token-store.ts`, `src/features/auth/api.ts`, `src/features/auth/LoginPage.tsx` |
| P3 401 interceptor + refresh | `src/api/client.ts`, `src/features/auth/api.ts`, `src/test/interceptor.test.ts` |
| P4 Optimistic mutation | add `src/features/tasks/api.ts` with `useUpdateTaskStatus` |
| P5 MSW handlers | `src/mocks/handlers.ts`, `src/mocks/browser.ts`, `src/main.tsx` |
| P6 Infinite scroll | add `src/features/projects/useProjectActivity.ts` + `ProjectActivityFeed.tsx` |

## MSW worker file

The browser worker (`public/mockServiceWorker.js`) is generated by:

```bash
npx msw init public/ --save
```

It is gitignored — regenerate locally after `npm install`.
