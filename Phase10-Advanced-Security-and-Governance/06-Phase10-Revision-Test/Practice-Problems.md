## Rubric

| Section | Pts |
|---|---|
| A — 12 quick-fire (2 pts each) | 24 |
| B — 3 diagrams (5 pts each) | 15 |
| C — 4 bug hunts (4 pts each) | 16 |
| D — 2 of 3 hands-on (12 pts each) | 24 |
| E — 3 cost/safety/governance (5 pts each) | 15 |
| F — Audit checklist | 6 |
| **Total** | **100** |
| **Pass** | **70** |

### Section-by-section scoring notes

- **A:** Full marks = sharp, correct, no padding. Half marks for partially correct.
- **B:** Full marks = correct flows, labelled, identifies tokens / scopes / trust direction explicitly.
- **C:** 2 pts identification + 2 pts fix.
- **D:** Code runs; repro steps work; security hygiene observed (no secrets, OIDC, MI, least-priv).
- **E:** Triage / response uses concrete commands or queries, not just prose.
- **F:** Ten checks, each with a specific query/portal blade and a "good" criterion.
